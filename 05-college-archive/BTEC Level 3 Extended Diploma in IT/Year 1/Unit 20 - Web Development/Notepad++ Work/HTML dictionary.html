H< sub >2< / sub >0The HTML element used to define subscripted text;letters that appear below the text baseline. Often used for formulas; for example, H2O.
illustration< sup >[1.1]< / sup >The HTML element used to define superscripted text; letters that appear above the text baseline. Often used for footnotes; for example, illustration [1.1].
< ins >inserted text< / ins >The HTML element used to indicate document modifications; specifically, newly inserted text.
< del >deleted text< / del > The HTML element used to indicate document modifications; specifically, deleted text. This is normally indicated by striking the deleted text, for example, deleted.
< mark >highlighted text< / mark >The HTML element used to highlight parts of text
< code >int x = 12;< / code >The HTML element used to define computer code in a document
< pre >Display this exactly as shown here, including the crazy spacesThe HTML element used to preformat text; in other words, display the content exactly as it is formatted in the HTML document, including white space and line breaks.
< abbr title="The World Wide Web Consortium">W3C< / abbr >The HTML element used to indicate abbreviations or acronyms; for example, W3C. The full name is normally displayed in a tooltip when the mouse hovers over the abbreviation/acronym.
< address >Walsall, United Kingdom< / address >The HTML element used to define the contact information of the owner/author of the HTML document.
< blockquote cite="http://www.rspca.org.uk">The RSPCA is the leading UK animal welfare charity.< / blockquote >The HTML element used to define a quote from another source.
< cite >James and the Giant Peach < / cite > is a popular children's novel.The HTML element used to define the title of a piece of work; for example, the title of a book.
